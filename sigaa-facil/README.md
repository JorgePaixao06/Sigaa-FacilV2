# SIGAA Fácil — guia independente para estudantes da UFPA

Site estático feito com HTML, CSS e JavaScript, sem React, TypeScript, Node.js, npm ou processo de build.

## Arquivos
- `index.html`: estrutura e conteúdo do site.
- `style.css`: visual e responsividade.
- `script.js`: pesquisa, filtros, tutoriais, checklist, progresso e avaliação local.

## Como testar
1. Extraia os arquivos.
2. Abra `index.html` no navegador.
3. Para editar, abra a pasta no VS Code.

## Como publicar no GitHub Pages
1. Envie `index.html`, `style.css`, `script.js` e `README.md` para a raiz do repositório.
2. No repositório, acesse **Settings → Pages**.
3. Em **Build and deployment**, escolha **Deploy from a branch**.
4. Selecione a branch `main` e a pasta `/ (root)`, depois clique em **Save**.
5. Aguarde a publicação e abra o endereço informado pelo GitHub Pages.

## Escopo e fontes
- O conteúdo foi direcionado ao SIGAA da Universidade Federal do Pará (UFPA).
- O site é um guia independente, não é um serviço oficial da UFPA.
- O site não faz login, não acessa dados acadêmicos e não realiza matrícula ou emissão de documentos.
- As orientações foram baseadas em materiais institucionais da UFPA, especialmente a página de manuais do CTIC, as orientações acadêmicas da PROEG, a página institucional sobre acesso ao SIGAA e orientações de unidades acadêmicas.
- Menus, prazos e procedimentos podem mudar. O estudante deve confirmar informações atuais nos canais oficiais e no calendário acadêmico.
- A avaliação de utilidade é armazenada apenas no `localStorage` do navegador; não existe painel ou banco compartilhado.
